# Laboratory of Numerical Simulation (LSN)

This repository contains the projects developed during the course **"Laboratory of Numerical Simulation" (Laboratorio di Simulazione Numerica)** at the **University of Milan**.

The course focused on the implementation and analysis of numerical methods for computational physics problems, with an emphasis on **C++ programming, statistical methods, stochastic simulations and data analysis**.

The repository includes C++ implementations of numerical algorithms together with Python notebooks for data analysis, visualization and interpretation of simulation results.

---

## Topics Covered

### Monte Carlo Methods

Implementation and analysis of stochastic numerical techniques, including:

- Random number generation and statistical validation
- Monte Carlo integration
- Importance sampling methods
- Statistical estimation and uncertainty analysis

---

### Molecular Dynamics Simulations

Development of molecular dynamics algorithms for the study of interacting particle systems:

- Simulation of physical systems with different interaction potentials
- Numerical integration of equations of motion
- Thermodynamic quantities estimation
- Analysis of equilibrium properties

---

### Optimization Algorithms

Implementation of optimization techniques for complex problems:

- Gradient-based optimization methods
- Evolutionary algorithms
- Parameter estimation and model fitting

---

### Statistical Physics and Stochastic Models

Simulation and analysis of probabilistic systems:

- Random processes
- Statistical distributions
- Error analysis
- Data-driven interpretation of numerical results

---

## Programming Languages and Tools

### C++

- Object-oriented programming
- Numerical algorithms implementation
- Scientific computing
- Simulation frameworks

### Python

Used for:

- Data analysis

- Statistical analysis
